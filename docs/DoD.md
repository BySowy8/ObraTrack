# Definition of Done (DoD) - ObraTrack

Para considerar terminada cualquier Historia de Usuario en el Sprint 1, debe cumplir con:
1. **Código y Control de Versiones:** Código funcional subido a GitHub en la rama correspondiente mediante Pull Request revisado por otro integrante.
2. **Persistencia de Datos:** Los registros de bitácora e imprevistos se guardan correctamente en la base de datos de manera permanente.
3. **Manejo de Errores e Interfaz:** La interfaz muestra mensajes visibles ante campos obligatorios vacíos o errores de conexión.
4. **Pruebas Funcionales:** Verificación manual exitosa de los flujos por un compañero de equipo.
